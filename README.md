## 🏔️ About me

I build tools and mods for **Celeste**: launchers, map editors, procedural generation and AI tooling that make mapmaking faster and mod installs safer.
Currently working on **Mount Zantas** and the **Desolo Zantas** mod.

- 🔭 Building: [Mount Zantas](https://github.com/Magedeline/mount-zantas), a Celeste launcher and mod manager
- 🗺️ Making: Desolo Zantas, a Celeste campaign mod
- 🤖 Exploring: MCP servers and AI agents for map editing
- 🐾 Fun fact: Meow

## ⭐ Featured projects

| Project | What it does | Stack |
|---|---|---|
| [**Mount Zantas**](https://github.com/Magedeline/mount-zantas) | Launcher and mod manager for Celeste: Everest installs, GameBanana browser, map preview. Every download is checksum-verified. | C# |
| [**Topo**](https://github.com/Magedeline/Topo) | Celeste map editor | C# |
| [**loenn-mcp**](https://github.com/Magedeline/loenn-mcp) | MCP server that lets AI agents read, edit and preview Celeste `.bin` maps | Python |
| [**loenn-vscode-editor**](https://github.com/Magedeline/loenn-vscode-editor) | Visual Celeste map editor inside VS Code | TypeScript |
| [**PCGHelper**](https://github.com/Magedeline/PCGHelper) | Procedural content generation toolkit for Celeste | Lua |
| [**KirbyHelperMechanics**](https://github.com/Magedeline/KirbyHelperMechanics) | Kirby-style mechanics for Celeste mods | C# |
| [**celestellaris-installer**](https://github.com/Magedeline/celestellaris-installer) | One-click installer for the Celestellaris mod | C# |

| [**fmod-mcp**](https://github.com/Magedeline/fmod-mcp) | MCP server for FMOD | Python |
